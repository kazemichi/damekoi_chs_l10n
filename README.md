## 汉化范围

- **已汉化**：对话、人名、选项
- **未汉化**：窗口标题、部分按钮



## 安装

将 `patch/` 目录下的**全部内容**复制到**游戏根目录**，OP/ED 的 dat 文件需要自行备份。

默认使用 [975 圆体](https://github.com/lxgw/975Yuan) 700W 字体，请自行安装。想要换其他字体，修改 SRL.ini 里 `To=霞鹜975圆体SC 700W` 即可。



## 卸载

运行 `删除汉化补丁.bat`，OP/ED 文件需要手动从备份还原。
